# Dead Cargo
## A Roguelike Horror Inventory Management Adventure

![Dead Cargo Game](generated-icon.png)

## Core Concept
"Dead Cargo" is a top-down roguelike survival game where players control a courier trapped in a cursed cargo ship filled with monstrous creatures. Inspired by Resident Evil's inventory system, players must carefully manage their limited inventory space to survive, loot supplies, and escape the ship.

## Gameplay Features

### Resident Evil-Style Inventory Management
- Players have a limited grid-based inventory where every item (weapons, healing items, tools) takes up space.
- Bigger weapons require more slots, forcing tough choices on what to carry.
- Players can find and equip inventory upgrades (backpacks, pouches) to expand capacity.

### Roguelike Elements
- Procedurally generated ship layouts ensure each run is unique.
- Each playthrough starts with different randomized supplies and weapons.
- Death is permanent, but players unlock persistent upgrades and new starting loadouts.

### Survival Horror Combat
- Players can use limited ammo firearms, melee weapons, or even throw objects to defend themselves.
- Enemies vary from slow, lumbering zombies to grotesque, mutated cargo creatures.
- Running and stealth are often better choices than fighting.

### Resource Scavenging & Crafting
- Players must search the ship for food, weapons, and tools.
- Crafting allows for ammo combinations, medkits, and traps to conserve inventory space.

### Escape Mechanic
- The ship has multiple escape methods (lifeboat, radio rescue, engine room repair), each requiring different key items and objectives to complete.

## Why It's Fun
- Tension comes from balancing limited inventory space with the need for resources.
- Each run feels fresh thanks to procedural generation.
- A mix of survival horror and roguelike mechanics keeps the gameplay engaging and unpredictable.

## Controls
- WASD keys for movement
- Right-click to aim
- Left-click while aiming to shoot
- E to interact with objects
- Tab to open inventory

## Technical Stack
- Built with React Three Fiber and TypeScript
- Custom procedural generation for rooms and items
- Real-time collision detection and combat mechanics
